# OctoAcme Project Management Docs

This README provides a short summary of OctoAcme's project management processes and direct links to the full process documents in the docs/ folder.

## Summary
OctoAcme follows an iterative, customer-focused project delivery approach with clear roles (PM, PdM, Developers, QA), a defined lifecycle (Initiation → Planning → Execution → Release → Retrospective), and supporting artifacts (Project One-pager, Backlog, Risk Register, Release notes). Team cadence includes daily standups, weekly delivery syncs, and regular retrospectives. Practices include CI-driven PR workflow, definition of done, and risk escalation paths.
